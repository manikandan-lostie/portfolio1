Download that index.html file above, then follow these steps to replace your old portfolio:

Step 1 — Open your repository
Go to: github.com/manikandan-lostie/portfolio

Step 2 — Delete the old index.html

	•	Click on index.html in the file list
	•	Click the trash icon (Delete file) at the top right
	•	Scroll down → click Commit changes

Step 3 — Upload the new one

	•	Back in the repository, click Add file → Upload files
	•	Upload the index.html file you downloaded above
	•	Click Commit changes

Step 4 — Wait ~1 minute
GitHub Pages auto-updates. Then visit:
👉 https://manikandan-lostie.github.io/portfolio/

Your new design will be live! ✅

If your repo has other files like an old style.css or script.js, you can delete those too — the new design has everything built into the single HTML file.
